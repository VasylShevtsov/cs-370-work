# StudyDock

StudyDock is an app wiefram for problem #1 "Managing study tasks, assignments, and deadlines in one place"

## Features

- Add tasks with a course, deadline, priority, and notes.
- See upcoming assignments on a dashboard.
- View task details and a weekly schedule.

## Core screens

1. Dashboard
2. Add Task
3. Task Details
4. Weekly Schedule

## Functional requirements

- Students can create tasks with a title, course, and due date and time.
- Students can view upcoming deadlines and open task details.

## Non-functional requirements

- Usability: A new user should be able to add a task within 2 minutes.
- Performance: The dashboard should load within 2 seconds.
